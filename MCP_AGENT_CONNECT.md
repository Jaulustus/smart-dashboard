# Stash MCP — Verbindungsanleitung (Deutsch)

Die **vollständige MCP-Dokumentation** liegt in der [README.md](README.md#mcp-model-context-protocol) (für GitHub und Englisch).

Dort findest du alles an einem Ort:

- MCP Agent UI in Stash (**MCP-Server** in der Navigation)
- Lokale Datenbank `agent_library.db`
- Installation (`requirements-agent.txt`)
- MCP-Tools-Referenz
- **Cursor**, **Claude Desktop**, **OpenClaw** und andere MCP-Clients
- Config-Vorlagen (`mcp-config.*.json`)
- Fehlerbehebung und Checkliste

## Schnellstart

1. Stash starten, Plugin laden  
2. Navigation **MCP-Server** → Abhängigkeiten installieren → **Gesamte Bibliothek scannen**  
3. MCP-Config aus der Sidebar kopieren oder `mcp-config.cursor.json` anpassen  
4. In Cursor / Claude / OpenClaw einfügen, Pfad zu `stash_mcp_server.py` setzen, Client neu starten  

Details: [README → MCP](README.md#mcp-model-context-protocol)
